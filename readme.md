<h2>📌 Project Overview</h2>
<p>
The <strong>RANDOM_PHP_WEBSITE</strong> repository contains a variety of PHP-based scripts, experimental 
web pages, prototypes, and practice files created while learning and experimenting with backend web development.  
Some projects are simple, some experimental — this repo acts as a playground for ideas and PHP exploration.
</p>

<h2>🎯 Purpose of This Repository</h2>
<ul>
  <li>Practice PHP fundamentals</li>
  <li>Experiment with small web applications</li>
  <li>Explore PHP forms, sessions, and database usage</li>

  <li>Serve as a learning archive for future reference</li>
</ul>

<h2>📥 1. Clone the Repository</h2>
<pre>
git clone https://github.com/PVegananda/RANDOM_PHP_WEBSITE
cd RANDOM_PHP_WEBSITE
</pre>

<br/>

<h2>🛠 2. Running the Project (Localhost)</h2>

<h3>Using XAMPP / WAMP / Laragon</h3>
<ol>
  <li>Install a local PHP server:</li>
  <ul>
    <li>XAMPP (recommended)</li>
    <li>WAMP</li>
    <li>Laragon</li>
  </ul>

  <li>Move the project folder into:</li>
</ol>

<pre>
htdocs/   ← for XAMPP  
www/      ← for WAMP  
www/      ← for Laragon  
</pre>

<ol start="3">
  <li>Start Apache server</li>
  <li>Open your browser and visit:</li>
</ol>

<pre>http://localhost/RANDOM_PHP_WEBSITE/</pre>
